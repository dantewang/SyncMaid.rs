## New

- **Regex filter rule.** Beside Path, Extension and Wildcard, a destination can now select
  files with a regular expression, searched for in the path relative to the source:
  `^photos/.*\.jpe?g$`, `IMG_\d{4}`, `\.(raw|dng|cr3)$`. Matching ignores case, folders are
  separated by `/`, and a pattern that is not valid is never saved. See
  [Filters](https://github.com/dantewang/SyncMaid.rs/blob/v0.4.0/docs/filters.md#regex-patterns).

## Before you go back to 0.3

**Do not run 0.3.x on a `Data` folder where 0.4.0 has saved a regex rule.** 0.3 does not know
the rule, so it cannot read `tasks.json`, and falls back to `tasks.json.bak`, the version saved
before that one. If the backup has no regex rule, 0.3 loads it without warning, and the next
time 0.3 saves, it writes that older copy over `tasks.json`. The regex rules and every change
saved after the backup are lost.

To go back safely, first remove every regex rule in 0.4.0 and save, or keep a copy of the
`Data` folder.
