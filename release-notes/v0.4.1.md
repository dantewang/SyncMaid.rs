## Fixed

- **A Recycle Bin delete that Windows refuses now says why.** When Windows declined to move a
  file to the Recycle Bin, the failure read only "Some operations were aborted". It now names the
  file and the reason: in use by another process, access denied, no Recycle Bin on that drive,
  too large for it.
- **A daily schedule no longer runs twice on the night clocks go forward.** A time in the hour
  before the change, such as `30 1 * * *` where clocks jump from 02:00 to 03:00, also fired just
  after the jump.
- **Chinese and Japanese text wraps where it should.** A line no longer starts with a lone `。`.

## Under the hood

Dependencies are up to date, and fewer of them: GPUI 0.9 (gpui-kit), croner 4, tray-icon 0.26.
Schedules written in the shorthand earlier versions accepted, such as `5/15 * * * *`, still load
and mean the same thing. The executable is the same size.
